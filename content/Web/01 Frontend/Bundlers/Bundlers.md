# Bundlers (Vite and webpack)

> [!abstract] TL;DR
> Inspect production artifacts, not only source. Do not expose a development server publicly; only explicitly public configuration belongs in browser bundles.

> [!info] Agent scope
> Module graphs; dev servers; production builds; tree shaking; source maps; environment-variable exposure; plugins.

## Cheatsheet

### From Import to Asset

Resolution maps each specifier to a module using aliases, package exports/conditions, extensions and filesystem rules. Loaders/transforms convert source into understood code; static analysis builds dependencies. The bundler groups modules into chunks and emits runtime linkage plus assets. The browser then loads those emitted URLs, not the original import graph. A checker resolving a path does not prove the bundler or runtime resolves it identically.

| Concern | Vite | webpack |
|---|---|---|
| Entry | HTML is part of the application graph | Explicit JS entry; HTML commonly generated by a plugin |
| Development | Native-ESM-oriented serving, transforms and HMR; version-specific dependency optimization | Compiler/watch/dev-server pipeline and runtime/HMR support |
| Production | Current Vite uses Rolldown; older releases used Rollup | webpack graph/chunks/runtime, optimizer and configured plugins |
| Transform extensions | Vite/plugin hooks, with version-specific engine capabilities | Loaders transform modules; plugins hook compilation lifecycle |
| Environment | Public `import.meta.env` replacements, `VITE_` prefix by default | Explicit DefinePlugin/EnvironmentPlugin or configured tooling |

Do not memorize “Vite always uses esbuild plus Rollup” as a timeless fact. Current docs and migration guides describe the Rolldown transition. Config option names, plugin hook compatibility and browser targets can change across majors; record versions and inspect actual build output. webpack 5 does not automatically provide every Node core polyfill for browser code.

### Tree Shaking, Chunks, and Side Effects

Tree shaking removes statically unused exports/code when semantics permit. ESM's static structure helps; CommonJS, computed imports and side-effectful module initialization can constrain removal. Minification compresses output and may remove proven-dead branches, but it is not the same process as determining module reachability. Never rely on either to conceal secrets.

The package `sideEffects` field is an assertion about module initialization. Marking every file side-effect-free can drop CSS imports, polyfills or registration code. A conditional fragment for a library with side-effectful styles is `"sideEffects": ["**/*.css"]`; use it only if all other modules genuinely have no observable import-time effects. Pure annotations are similarly semantic promises, not universal size flags.

Dynamic `import()` returns a promise and often creates an async chunk. The exact chunk count/names are optimizer decisions. It can fail after deployment if old HTML references deleted chunks, public paths are wrong, a proxy serves HTML for a JS URL, or connectivity fails. Deploy HTML and assets coherently; retain immutable hashed assets long enough for old sessions, and avoid infinitely cached entry HTML. Vite `base` and webpack `output.publicPath` must match hosting paths.

### Environment and Source Maps

Vite env values are strings except documented built-ins; `'false'` is truthy. Mode selection and NODE_ENV are related but not identical concepts. `.env` loading occurs at tool-defined times; restart development after relevant configuration changes. A public-prefixed variable is intentionally client-visible. DefinePlugin replaces code expressions: use `JSON.stringify` for string literals, and define individual public identifiers instead of replacing all of `process.env`.

| Map choice | What ships / tradeoff |
|---|---|
| Full external source map | Mapping file, usually original sourcesContent; useful debugging, publication decision required |
| Hidden map | Map file without an advertised sourceMappingURL; not access control |
| nosources map | Omits original source bodies but still reveals paths/structure/mappings |
| Inline map | Embedded in JavaScript; excluding `.map` files does not remove it |
| Disabled | No generated map from that setting; plugins/copied files still need inspection |

Maps can retain unused source text that was removed from executable code. Inspect executable JS for tree-shaking assertions and all publishable files for exposure assertions. Development eval-based webpack map modes can conflict with strict CSP; do not broaden production CSP merely to accommodate a development artifact.

### Plugins and Diagnostic Workflow

Build configs, loaders and plugins execute with the build process's filesystem/environment/network authority. A plugin that only appears to format HTML can still run arbitrary build-time code. Review additions and lockfile changes, isolate credentials, and use clean reproducible installs after resolution. A dev server is not a production server; loopback binding, host policy and filesystem restrictions are separate controls.

Diagnose source syntax, resolution, transform, chunk loading and runtime errors separately. TypeScript transpilation in Vite does not substitute for `tsc --noEmit`; webpack needs an explicit checker/transpiler setup if TypeScript is used. Inspect stats/build logs and Network initiators before changing optimization settings.

## Gotchas

A variable's name does not make it secret. Build-time replacement can publish a value even if its source configuration file is ignored by Git.

## Labs

### Environment and Complete Files

Node 22.12+ within major 22 satisfies the currently documented Vite baseline; use a supported Node version satisfying every selected package's engines. npm, webpack 5/webpack-cli, HtmlWebpackPlugin and current Vite are required. Python 3.12+ optionally serves built artifacts. Install records exact resolved versions; no patch release is asserted tested.

Create `bundler-graph-lab` with all ten files below. Both build systems consume the same three JavaScript source files. No real secrets are present; PRIVATE-LAB-ONLY is a synthetic absence marker.

### File: package.json

```json
{"name":"bundler-graph-lab","private":true,"type":"module",
 "scripts":{"build:vite":"vite build",
 "build:webpack":"node --env-file=.env ./node_modules/webpack-cli/bin/cli.js --config webpack.config.cjs",
 "check":"node check.mjs"}}
```

### File: .env

```dotenv
VITE_PUBLIC_LABEL=PUBLIC-LAB-7
SERVER_ONLY_MARKER=PRIVATE-LAB-ONLY
```

### File: index.html

```html
<!doctype html><html lang="en"><head><meta charset="utf-8"><title>Vite graph</title></head>
<body><main><h1>Module graph</h1><p id="result"></p><button id="details">Details</button>
<output id="detail"></output></main><script type="module" src="/src/main.js"></script></body></html>
```

### File: webpack.html

```html

<body><main><h1>Module graph</h1><p id="result"></p><button id="details">Details</button>
<output id="detail"></output></main></body></html>
```

### File: src/math.js

```js
export function double(value) { return value * 2; }
export function unused() { return 'UNUSED-LAB-MARKER'; }
```

### File: src/detail.js

```js

```

### File: src/main.js

```js
import { double } from './math.js';
document.querySelector('#result').textContent = `${import.meta.env.VITE_PUBLIC_LABEL}: ${double(7)}`;
document.querySelector('#details').addEventListener('click', async () => {
	try {
		const detail = await import('./detail.js');
		document.querySelector('#detail').textContent = detail.describe();
	} catch {
		document.querySelector('#detail').textContent = 'Detail unavailable; reload after deployment';
	}
});
```

### File: vite.config.js

```js
import { defineConfig } from 'vite';
export default defineConfig({
	base: './',
	server: {host: '127.0.0.1', strictPort: true, allowedHosts: ['localhost']},
	build: {outDir: 'dist/vite', sourcemap: true, emptyOutDir: true}
});
```

### File: webpack.config.cjs

```js
const path = require('node:path');
const webpack = require('webpack');
const HtmlWebpackPlugin = require('html-webpack-plugin');
module.exports = {
	mode: 'production', entry: './src/main.js', devtool: 'source-map',
	output: {path: path.resolve(__dirname, 'dist/webpack'), filename: '[name].[contenthash].js',
		chunkFilename: '[name].[contenthash].js', publicPath: 'auto', clean: true},
	plugins: [new HtmlWebpackPlugin({template: './webpack.html'}),
		new webpack.DefinePlugin({
			'import.meta.env.VITE_PUBLIC_LABEL': JSON.stringify(process.env.VITE_PUBLIC_LABEL)
		})]
};
```

### File: check.mjs

```js
import assert from 'node:assert/strict';
import { readdir, readFile } from 'node:fs/promises';
import { join } from 'node:path';
async function files(root) {
	const found = [];
	for (const entry of await readdir(root, {withFileTypes: true})) {
		const path = join(root, entry.name);
		if (entry.isDirectory()) found.push(...await files(path));
		else found.push(path);
	}
	return found;
}
for (const root of ['dist/vite', 'dist/webpack']) {
	const paths = await files(root);
	const entries = await Promise.all(paths.map(async path => [path, await readFile(path, 'utf8')]));
	const code = entries.filter(([path]) => path.endsWith('.js')).map(([, text]) => text).join('\n');
	assert.ok(code.includes('PUBLIC-LAB-7'), `${root}: public substitution`);
	assert.ok(!code.includes('UNUSED-LAB-MARKER'), `${root}: unused function removed`);
	assert.ok(entries.every(([, text]) => !text.includes('PRIVATE-LAB-ONLY')), `${root}: private absence`);
	assert.ok(paths.some(path => path.endsWith('.map')), `${root}: maps generated`);
	console.log(`PASS ${root}: public value, tree shaking, private absence, maps`);
}
```

### Hints

HTML templates differ because Vite follows its module script while HtmlWebpackPlugin injects built scripts. The env variable is replaced at build time, not read from the user's machine at runtime. Dynamic import is a load boundary; exact chunk names/hashes are not acceptance criteria.

### Solution and Expected Results

Both pages display PUBLIC-LAB-7: 14. Details displays Lazy detail loaded and normally loads an async chunk on first use. Check prints two PASS lines. Executable JS lacks UNUSED-LAB-MARKER, but a full source map may contain it in sourcesContent. PRIVATE-LAB-ONLY must be absent everywhere in both output trees. Changing an input and rebuilding can change hashes; that is cache invalidation, not nondeterminism evidence by itself.

### Verification, Troubleshooting, and Cleanup

Missing public label in webpack means the command did not load `.env` or an existing environment variable overrode it. A blank production page can be an incorrect base/publicPath, wrong serving directory or HTML returned as JavaScript. Do not open built modules over file URLs. If a tree-shaking assertion fails, inspect whether the export became used or a plugin changed optimization. Stop your static server and delete only the disposable project. Preserve versions/lockfile if retaining evidence. No install, build, server or checks were executed during authoring.
